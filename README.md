# Модель лесного пожара с учётом влажности и ветра
## Особенности и параметры модели
Модель пространства представляет из себя две двумерных регулярных решётки размером N строк на M столбцов. В одной из решёток находится «лес», вторая же является «зеркалом» первой, на которой отражена карта уровня влажности воздуха клеток. Особенности и параметры модели:
- Окрестность: Неймана или Мура;
- Клетка может принимать 3 состояния s:
  - s = 0 – пустая клетка;
  - s = 1 – клетка с деревом;
  - s = 2 – клетка с горящим деревом.
- Условия возгорания клетки с деревом:
	- С некоторой вероятностью f происходит произвольное возгорание;
	- Уровень влажности воздуха в клетке уменьшает вероятность возгорания;
	- В окрестности клетки не менее k горящих деревьев;
	- Уровень влажности воздуха и ветер задают вероятность возгорания.
- На месте сгоревшего дерева (дерево сгорает за один такт) образуется пустая клетка, влажность воздуха в сгоревшей клетке обнуляется;
- На пустой клетке с некоторой вероятностью p вырастает новое дерево;
  - Дерево может вырасти в случае, если по соседству нет горящих клеток;
	- Влажность воздуха немного повышает вероятность роста дерева.
- Клетка с деревом с некоторой вероятностью может повысить свой уровень влажности воздуха на некоторое значение, но не выше порога в 75%;
- Влага может перераспределяться между клетками:
	- В случае отсутствия ветра – равномерно между соседними клетками, если разница уровней между ними не менее порога ∆H;
	- В случае наличия ветра – сначала равномерно, затем по направлению ветра, с некоторым задаваемым значением, если разница уровней между ними не менее порога ∆H.
- С некоторой вероятностью раз в некоторое число тактов, в 10% (от общего числа) случайных клетках сетки выпадает дождь, повышая влажность воздуха в этих клетках до случайного значения в пределах (0.90 … 0.99);
- За границами области нет деревьев (фиксированные граничные условия);
- Состояние обновляется синхронно.
Распределение деревьев в области генерируется случайным образом, притом уже горящих деревьев не генерируется. Распределение влажности воздуха генерируется случайным образом (алгоритм шума Перлина).

## Программная реализация

После запуска программы в консоль выводится меню вида:
1.  **Текущие параметры** — просмотр установленных коэффициентов.
2.  **Ввод параметров** — изменение настроек симуляции в реальном времени.
3.  **Расчёт КА** — запуск симуляции, вывод графиков и сохранение анимации.
4.  **Выход** — завершение работы.

Задаваемые в п.2 параметры:
*   `N`, `M` — размеры сетки (минимум 2x2).
*   `t` — количество шагов.
*   `inter` — задержка между кадрами визуализации (в миллисекундах).
*   `trees_to_ign` — минимальное число горящих соседей для возгорания.
*   `areatype` — тип окрестности ячейки (`0` — Неймана, `1` — Мура).
*   `p_fire` — базовая вероятность случайного возгорания.
*   `p_grow` — базовая вероятность роста дерева.
*   `H_diff_por` — порог разницы влажности воздуха между клетками для диффузии.
*   `p_grow_H_w` — коэффициент влияния влажности воздуха на ускорение роста деревьев.
*   `p_tree_H_gen` — вероятность выделения влаги деревом.
*   `tree_H_gen` — объём выделения влаги деревом.
*   `p_rain` / `p_rain_check` — вероятность выпадения дождя и периодичность проверки (в шагах) его выпадения.
*   `wind_v` — сила ветра (0 — выключен).
*   `wind_dir` — направление ветра в градусах (0° — вверх, 90° — вправо, 180° — вниз, 270° — влево).
*   `wind_w` — весовой коэффициент силы влияния ветра на огонь и влагу.
*   `wind_H_transfer` — количество переносимой ветром влаги за один шаг.

В результате расчёта по п.3, выводом являются график с последнего шага, текстовый вывод в консоль количества клеток конкретных типов, среднего значения влажности воздуха по сетке, а также анимация работы клеточного автомата "animation.gif", которая сохраняется в папке с программой.
